CAT REACTION ASSETS
===================

The tracker reads its reaction files from `cat-reactions/`. Filenames describe
the matching pose or expression: `chill`, `thumbs-up`, `pointing-up`,
`pointing-front`, `punch`, `heart`, `desperate`, `scared`, and the supported
face reactions `happy`, `tongue-out`, and `scuba`.

Note: If images are not found, the program will create colored 
placeholder images with the gesture name on them.
